### Added
- Initial release
- Azure AD (Microsoft) Socialite authentication for Filament v3 and v4
- Multi-panel support with panel-aware routes and guards
- Auto-registration of Socialite provider
- Auto-computed redirect URIs per panel
- Email domain restrictions
- Azure tenant ID restrictions
- Fluent configuration API
- Artisan install command for setup guidance
- Artisan doctor command for configuration validation
- Custom user resolution hooks
- Before redirect and after user resolved callbacks
- Comprehensive error handling with Filament notifications
- Support for Laravel 10, 11, and 12
- Support for Filament v3 and v4
